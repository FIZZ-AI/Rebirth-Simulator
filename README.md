# 投胎模拟器

一个基于 AI 的人生模拟网页游戏，使用 PlayKit SDK 驱动。

## 游戏简介

《投胎模拟器》让你体验一段由 AI 推演的人生旅程。从出生开始，你可以在关键时刻介入最多 3 次来影响人生轨迹，目标是积累更多财富并体验完整的人生故事。

## 核心特性

- 🎮 **AI 驱动**：所有人生事件和世界背景由 AI 生成
- 🖼️ **图像生成**：每个年龄段自动生成对应的人物照片
- 🎯 **介入系统**：最多 3 次机会改变人生轨迹
- 💬 **提问系统**：随时询问当前人生状态
- 📊 **属性系统**：健康值、财富值动态变化
- 🎨 **响应式设计**：支持桌面和移动设备

## 快速开始

### 方式 1：直接打开（推荐）

1. 下载所有文件到本地
2. 双击打开 `index.html` 文件
3. 开始游戏！

### 方式 2：使用本地服务器

```bash
# 使用 Python
python -m http.server 8000

# 或使用 Node.js
npx http-server
```

然后在浏览器中访问 `http://localhost:8000`

## 游戏玩法

### 1. 设定出生信息
- 输入出生年份（例如：1990）
- 输入出生地点（例如：深圳）
- 输入婴儿寄语（给未来的自己）

### 2. 推进人生
- 点击"推进年龄"按钮，AI 会推演接下来 5 年的人生
- 每次推演会生成：
  - 世界背景变化
  - 人生事件
  - 健康值变化
  - 财富值变化
  - 当前年龄的照片

### 3. 介入人生
- 剩余介入次数 > 0 时可以使用
- 输入建议（例如：多读书、去创业、注意健康）
- AI 会在下次推演时尝试采纳你的建议

### 4. 提问系统
- 随时询问关于当前人生状态的问题
- 例如："我现在过得开心吗？"
- AI 会基于你的人生历程给出回答
- 提问不会影响游戏数值

### 5. 游戏结束
当以下任一条件满足时，游戏结束：
- 健康值降至 0
- 年龄达到 100 岁

结算时会显示：
- 完整的人生总结
- 所有生成的照片
- 最终财富值
- 总结小诗

- **前端**：原生 HTML + CSS + JavaScript
- **AI 服务**：PlayKit SDK
- **文本模型**：gpt-4o
- **图像模型**：flux-1-schnell

### 生产环境部署

如果要部署到生产环境，请：
1. 移除 `DEVELOPER_TOKEN` 配置
2. 游戏会自动提示用户登录 PlayKit 账号
3. 确保使用 HTTPS 协议

## 开发说明

### 环境检测

游戏会自动检测运行环境：
- **开发环境**：file:// 协议或 localhost
- **生产环境**：其他域名

开发环境会在控制台输出详细日志。

### 核心类

- **GameStateManager**：管理游戏状态
- **PageController**：管理页面切换和 UI 更新
- **PlayKitManager**：管理 PlayKit SDK
- **AIEngine**：处理 AI 调用
- **EventHandlers**：处理用户交互

## 常见问题

### Q: 游戏加载失败？
A: 检查网络连接，确保能访问 PlayKit SDK CDN。

### Q: AI 推演失败？
A: 可能是 Spark 积分不足，或网络问题。请重试。

### Q: 照片生成很慢？
A: 图像生成需要一定时间，请耐心等待。

### Q: 如何重新开始？
A: 在结算页面点击"重新开始"按钮。
